1.4.2. Text Buffer & Manipulation¶

Description and Priority¶

Priority: High

The Text Buffer is the conceptual source of truth of the text. It is modeled as a continuous sequence of characters.

The buffer defines the observable state of the text. All text manipulation operations modify this state.

State Invariants¶

Invariant: Empty Buffer Definition INV-TEXT-001
tags: buffer

The buffer must always represent at least one logical line. An empty buffer is defined as a buffer containing zero characters.
Invariant: Left-to-right Script INV-TEXT-002
tags: buffer

The buffer must be processed in a left-to-right manner. Therefore a character “in front of” the cursor is visually to the right of the cursor. A character “behind” the cursor is visually to the left of the cursor.

Preconditions¶

All operations in this section assume a valid cursor position as defined in Cursor Specification.

Stimulus/Response Sequences¶

  • Stimulus: External system provides a sequence of characters to insert.

    Response: The system inserts the characters at the current cursor position and updates the cursor position accordingly.

  • Stimulus: External system triggers delete.

    Response: The system removes the character immediately right of the cursor, if present.

  • Stimulus: External system triggers backspace.

    Response: The system removes the character immediately left of the cursor, if present, and updates the cursor position.

Functional Requirements¶

Requirement: Text Buffer FR-TEXT-001
status: Open
tags: text

The system must maintain an internal representation of text that is not externally mutable.
Requirement: Text Buffer Mutation FR-TEXT-002
status: Open
tags: text

The text buffer must only be modified through defined system operations.

Insertion¶

Requirement: Insert Operation Support FR-TEXT-011
status: Open
tags: insert

The system must support insertion of a sequence of characters.
Requirement: Insert at Cursor Position FR-TEXT-012
status: Open
tags: insert
links outgoing: FR-CURSOR-001

Characters must be inserted at the current cursor position.
Requirement: Inserting Nothing FR-TEXT-013
status: Open
tags: insert, no-op

Inserting zero characters must result in a no-op.
Requirement: No Overwrite FR-TEXT-014
status: Open
tags: insert

Insertion must not overwrite existing characters.
Requirement: Cursor Update After Insert FR-TEXT-015
status: Open
tags: insert
links outgoing: FR-CURSOR-001

After insertion, the cursor must be positioned immediately after the inserted characters.
Requirement: Inserting Newline FR-TEXT-016
status: Open
tags: insert

Newline characters (\n) may be inserted and must introduce a new logical line.
Requirement: Insert Atomicity FR-TEXT-017
status: Open
tags: insert
links incoming: FR-INIT-002

Inserting a sequence of multiple characters must produce the same resulting buffer state and cursor position as inserting each character of the sequence sequentially.

Delete¶

Requirement: Delete Operation Support FR-TEXT-021
status: Open
tags: delete
links outgoing: FR-CURSOR-001

The system must support a delete operation that targets the character immediately right of the cursor.
Requirement: Single Character Deletion FR-TEXT-022
status: Open
tags: delete
links outgoing: FR-CURSOR-001

The delete operation must remove exactly one character immediately right of the cursor, if such a character exists.
Requirement: Cursor Position on Delete FR-TEXT-023
status: Open
links outgoing: FR-CURSOR-001

The delete operation must not change the cursor position.
Requirement: Delete Boundary Behavior FR-TEXT-024
status: Open
tags: delete, no-op

If no character exists to the right of the cursor, the delete operation must result in a no-op.
Requirement: Newline Character Deletion FR-TEXT-025
status: Open
tags: delete
links incoming: FR-CURSOR-012

Deleting a newline character must merge the two adjacent logical lines.

Backspace¶

Requirement: Backspace Operation Support FR-TEXT-031
status: Open
tags: backspace
links outgoing: FR-CURSOR-001

The system must support a backspace operation that targets the character immediately left of the cursor.
Requirement: Single Character Deletion FR-TEXT-032
status: Open
tags: backspace
links outgoing: FR-CURSOR-001

The backspace operation must remove exactly one character immediately left of the cursor, if such a character exists.
Requirement: Cursor Position on Backspace FR-TEXT-033
status: Open
tags: backspace
links outgoing: FR-CURSOR-001

If a character to the left of the cursor is removed, the cursor must move one position to the left.
Requirement: Backspace Boundary Behavior FR-TEXT-034
status: Open
tags: backspace

If no character exists to the left of the cursor, the backspace operation must result in a no-op.
Requirement: Newline Character Backspace FR-TEXT-035
status: Open
tags: backspace
links incoming: FR-CURSOR-012

Removing a newline character via backspace must merge the two adjacent logical lines.

Control Characters¶

Control characters are required to be handled as follows:

Requirement: New Line FR-TEXT-041
status: Open
tags: special
links incoming: FR-TEXT-043

The system must support the newline character (\n) as a character.
Requirement: Other Control Characters FR-TEXT-042
status: Open
tags: special
links incoming: FR-TEXT-043

The system must handle any other Control Character as just another character. They must not be ignored/ removed. They must be inserted and returned as-is, with no special behavior.
Requirement: Line-Ending Characters FR-TEXT-043
status: Open
tags: special
links outgoing: FR-TEXT-041, FR-TEXT-042

Line-ending characters (\r and \r\n) must be handled as regular characters. \r\n is treated as two separate characters, \r and \n and handled as defined in New Line (FR-TEXT-041).

Out of Scope¶

Non-Requirement: Text Selection NR-TEXT-101
tags: out-of-scope

The system must not support text selection.
Non-Requirement: Clipboard Functions NR-TEXT-102
tags: out-of-scope

The system must not support copy, cut, or paste operations.
Non-Requirement: Undo / Redo NR-TEXT-103
tags: out-of-scope

The system must not support undo or redo functionality.
