1.4.3. Cursor & Movement¶

Description and Priority¶

Priority: High

The cursor is a position in the text buffer that determines where text manipulation operations occur.

The cursor can be represented in multiple coordinate systems to serve different functional layers, corresponding to the four output modes:

  1. Absolute Index (index) - Source of truth for text manipulation.

  2. Logical Coordinate ([row, col]) - Relevant for distinguishing logical lines (e.g., line numbers).

  3. Visual Coordinate ([v_row, v_col]) - Relevant for text layout, rendering, and visual navigation.

  4. Window Coordinate ([x, y]) - Relevant for displaying text within a viewport. Note: [x, y] are not pixel coordinates. The system does not operate with pixels. y denotes the visible line index within the viewport (where y=0 is the first display line, not necessarily the first visible line). x denotes the column/character index.

State Invariants¶

Invariant: Valid Coordinate Ranges INV-CURSOR-001
links outgoing: INV-WRAP-001, INV-VIEW-001
links incoming: INV-CURSOR-003, FR-CURSOR-002, FR-CURSOR-003, FR-CURSOR-004, FR-CURSOR-005, FR-CURSOR-010, INV-INIT-002, FR-INIT-006

The cursor must always refer to a valid logical and visual position within the bounds of the text buffer.

The valid ranges for the respective coordinate systems are:

  • Absolute Index:

    • 0 <= index <= len(text)

  • Logical Coordinate

    • 0 <= row < num_logical_lines

    • 0 <= col <= len(logical_line)

  • Visual Coordinate:

    • 0 <= v_row < num_visual_lines

    • 0 <= v_col <= len(visual_line) <= display_width

  • Window Coordinate:

    • 0 <= y < display_height

    • 0 <= x <= len(visual_line) <= display_width
Invariant: Inter-Character Positioning INV-CURSOR-002

The cursor must always refer to a position between characters, not on a character itself.
Invariant: Coordinate Synchronization INV-CURSOR-003
links outgoing: INV-CURSOR-001
links incoming: FR-CURSOR-040

Valid Absolute Index, Logical Coordinate, Visual Coordinate, and Window Coordinate values must bijectively map to the exact same underlying position in the text buffer. A change in one representation must be perfectly reflected in the others.

Exception: Virtual Position at Display... (FR-CURSOR-010) boundary case.

Preconditions¶

All operations in this section assume a valid, initialized text buffer as defined in Text Buffer Specification.

Operations relying on visual representations (Visual Coordinates, Window Coordinates, Cursor Movement) assume valid, initialized viewport, display height and display width.

Stimulus/Response Sequences¶

  • Stimulus: An external system or user triggers a horizontal cursor movement (e.g., left, right).

    Response: The system adjusts the cursor, implicitly wrapping across visual lines if necessary, and updates all coordinate representations.

  • Stimulus: An external system or user triggers a vertical cursor movement (e.g., up, down).

    Response: The system calculates the new Visual Coordinate relative to the visual lines, truncating the visual column if the target line is shorter, and applies the update.

  • Stimulus: An external system or user triggers a boundary cursor movement (e.g., home, end).

    Response: The system updates the cursor to the absolute start (index 0) or absolute end (index len(text)) of the text buffer.

  • Stimulus: Text is inserted or deleted at the current cursor.

    Response: The text is manipulated, and the cursor implicitly updates its coordinates to remain logically consistent with the surrounding text boundary.

Functional Requirements¶

Cursor Position & Coordinates¶

Requirement: Mutable Cursor Position FR-CURSOR-001
status: Open
tags: cursor, state
links incoming: FR-TEXT-012, FR-TEXT-015, FR-TEXT-021, FR-TEXT-022, FR-TEXT-023, FR-TEXT-031, FR-TEXT-032, FR-TEXT-033

The system must maintain a mutable cursor. No text manipulation operation may bypass the cursor.
Requirement: Absolute Position Representation FR-CURSOR-002
status: Open
tags: cursor, position
links outgoing: INV-CURSOR-001

The system must provide an interface to return the cursor as an Absolute integer Index.

An Absolute Index value equal to len(text) represents the position immediately after the last character in the text buffer.
Requirement: Logical Coordinate Representation FR-CURSOR-003
status: Open
tags: cursor, coordinates
links outgoing: INV-CURSOR-001

The system must provide an interface to return the cursor as a Logical Coordinate [row, col]. A col value equal to the logical line length represents the position immediately after the last character (before the newline delimiter).
Requirement: Visual Coordinate Representation FR-CURSOR-004
status: Open
tags: cursor, coordinates
links outgoing: INV-CURSOR-001

The system must provide an interface to return the cursor as a Visual Coordinate [v_row, v_col] representing its location across all wrapped visual lines. A v_col value equal to the visual line length represents the position immediately after the last character on that visual segment.
Requirement: Window Coordinate Representation FR-CURSOR-005
status: Open
tags: cursor, coordinates
links outgoing: INV-CURSOR-001
links incoming: FR-VIEW-004

The system must provide an interface to return the cursor as a Window Coordinate [x, y] representing its location within the visible viewport. An x value equal to display_width represents a position resting at the extreme right edge of the window.

Edge Case: Boundary wrapping¶

Requirement: Virtual Position at Display Width FR-CURSOR-010
status: Open
tags: cursor, boundary, rendering
links outgoing: FR-WRAP-003, INV-CURSOR-001

When the cursor is positioned at the exact boundary of a wrapped logical line (e.g. [row, N * display_width], where N is a positive integer), the Visual Coordinate must be represented as resting at the start of the next visual line ([v_row, 0]). The system must normalize any input of [v_row, display_width] to [v_row + 1, 0].

Exception: When the cursor is positioned at the end of a logical line, whose final visual line is exactly display_width characters long, (Break Logic (Character-Based) (FR-WRAP-003)) the Visual Coordinate must be represented as [v_row, display_width] instead. Since the visual line v_row+1 doesn’t exist.
Requirement: Newline Insertion at Boundary FR-CURSOR-011
status: Open
tags: cursor, boundary, insert

Inserting a newline character when the cursor is at a wrapped boundary ([v_row + 1, 0]) must move the cursor to the start of the newly created logical line ([row + 1, 0], [v_row + 1, 0]).
Requirement: Newline Deletion at Boundary FR-CURSOR-012
status: Open
tags: cursor, boundary, delete
links outgoing: FR-TEXT-025, FR-TEXT-035

Deleting a newline character (via delete) must keep the cursor indices unchanged.

Deleting a newline character (via backspace) when the cursor is at the start of a logical line ([v_row, 0]) must move the cursor to the end of the previous logical line. (Now merged into one logical line.)

Cursor Movement¶

Requirement: Movement Operations FR-CURSOR-020
status: Open
tags: movement

The cursor must support basic movement: up, down, (see Vertical Movement) left, and right, (see Horizontal Movement) as well as boundary jumps to the home and end of the text buffer. (See Boundary Behaviors)
Requirement: Non-Destructive Movement FR-CURSOR-021
status: Open
tags: movement

Changing the cursor must strictly be a navigation operation and must not modify the text buffer.

Vertical Movement¶

Requirement: Visual Line Basis FR-CURSOR-030
status: Open
tags: movement, vertical

Vertical movements (up or down) must be evaluated relative to the visual lines, transparently crossing wrapped boundaries without requiring distinct logic for logical lines.
Requirement: Target Visual Line Truncation FR-CURSOR-031
status: Open
tags: movement, vertical
links outgoing: NR-CURSOR-101

When moving vertically, the system must preserve the current visual column (v_col).

Exception: Only if the target visual line is shorter than the current v_col, the system must truncate the new position to the end of the target visual line (its maximum valid v_col).

Horizontal Movement¶

Requirement: Horizontal Absolute Shifting FR-CURSOR-040
status: Open
tags: movement, horizontal
links outgoing: INV-CURSOR-003

Moving the cursor left or right must strictly decrement or increment the Absolute Index by exactly 1, respectively. By definition of Coordinate Synchronization (INV-CURSOR-003), this inherently handles all appropriate wrapping across visual lines and logical lines.

Boundary Behaviors¶

Requirement: Vertical Boundary Extremes FR-CURSOR-050
status: Open
tags: movement, boundary

Moving up from any valid position on the first visual line must relocate the cursor to the absolute start of the text. Moving down from any valid position on the last visual line must relocate the cursor to the absolute end of the text.
Requirement: Inoperative Extents FR-CURSOR-051
status: Open
tags: movement, boundary, no-op

Moving left at the absolute start of the text, or moving right at the absolute end of the text, must not alter the cursor (No-Op).
Requirement: Move Home FR-CURSOR-052
status: Open
tags: movement, boundary

Moving home must relocate the cursor to the start of the text buffer.

Equivalent to setting the absolute index to 0.
Requirement: Move End FR-CURSOR-053
status: Open
tags: movement, boundary

Moving end must relocate the cursor to the end of the text buffer.

Equivalent to setting the absolute index to the length of the text buffer.

Out of Scope¶

Non-Requirement: Desired Column Retention NR-CURSOR-101
tags: out-of-scope, movement
links incoming: FR-CURSOR-031

The system is currently not required to support a “Desired Column” or “Sticky Ghost Cursor” feature (the ability to memorize the furthest v_col position when navigating vertically across shorter intermediate lines).
Non-Requirement: User Input NR-CURSOR-102
tags: out-of-scope, movement

The system does not capture keyboard or mouse events All “typing” or “clicking” must be translated into API calls by the host application.
